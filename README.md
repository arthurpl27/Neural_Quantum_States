# Neural-Quantum-States
This repository contains the following files:

(1) Ising_Model_MH : A short implementation of a 2D Ising Model on a (50 x 50) lattice with a Metropolis-Hastings algorithm to estimate the energy of the system.

(2) MF_Ansatz : A (useless) neural quantum state with an implementation of a Mean-Field Ansatz on a (4 x 4) Transverse Field Ising Model based on 16 parameters (trainable weights). Update via naive gradient descent and no use of stochastic sampling (we perform an extraction of all the states in the Hilbert space). This implementation is just to get a gist of how NetKet works.  

(3) Jastrow_Ansatz : A (useless) neural quantum state with an implementation of a Jastrow Ansatz on a (4 x 4) Transverse Field Ising Model based on 16 parameters (trainable weights). Update via naive gradient descent and no use of stochastic sampling (we perform an extraction of all the states in the Hilbert space).
